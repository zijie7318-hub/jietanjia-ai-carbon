## 真实浏览器流程

使用无头 Edge 加载本地 Flask 页面并完成交互：

1. 首屏加载成功，默认进入节能方案，数据版本显示 12 项措施、1 条已接入政策。
2. 选择“三口自住”示例并提交，生成 3 张方案卡和 1 条“条件待确认”的真实西安政策卡，官方原文链接可点击。
3. 方案卡可带入碳迹日记，默认状态为“计划执行”。
4. 无模型 Key 时，碳迹反馈使用本地模板，AI 解释区域不出现。
5. 配置本地模型桩后，AI 解释区域生成说明，检索元数据显示 3 个政策条款片段。
6. 模型返回异常时，方案卡不受影响，AI 区域自动显示规则解释。
7. 注册新账号后可保存碳迹，碳档案显示“计划执行”，总数正确。
8. 390px 视口 `documentElement.scrollWidth === innerWidth`，无横向溢出。
9. 三个措施分类右边界均为 333px，固定列对齐；方案摘要初始隐藏，生成后显示。
10. `/api/create-order` 等旧接口返回 404；页面接口固定同源。
11. 生态环境部因子附件、陕西电价政府页面、西安市商务局政策细则和实施公告共 4 个链接均返回 HTTP 200。

## 前端模块化与流式改造

- `backend/index.html` 从 2110 行降到 1330 行，交互逻辑拆成 `backend/static/js/` 下 9 个模块，
  按 `core → ai-config → nav → ai-explain → plans → diary → account → ai-modal → boot` 加载；
- 使用普通脚本而非 ES module，`file://` 直接打开仍可用；页面不引用任何第三方脚本；
- 无头 Edge 加载真实页面：`12 项措施 · 1 条已接入政策` 正常渲染，控制台无脚本错误；
- AI 解释改为 SSE：`start → stage → delta… → done → end`，逐字渲染后替换为服务端校验结构；
- 模型异常或输出含承诺/数字时改发 `fallback` 事件，界面展示规则说明，方案卡不受影响。
